# Security Policy

## Supported versions

Security fixes are made for the latest release on the `main` branch. Update before you report.

## Reporting a vulnerability

Please do **not** open a public issue for exploits, dupes, permission bypasses or anything that could be
used against live servers.

Report it privately:

1. Join the [JRS Core Discord](https://discord.gg/jrscore).
2. Open a ticket and choose **help**.
3. Send the resource name, what the problem allows, and the steps to reproduce it.

You will get an answer from the team in the ticket. Please give us time to fix and release before you
talk about it in public. Reporters are credited in the changelog if they want to be.
